# Destan Online — handoff

Türkçe yanıt ver. Ürün adı: **Destan Online**. Site: https://destanonline.com

## Kaynak
- GitHub (yerelleştirme): https://github.com/okedidirkedi/destan-online
- Studio projesi: yerel disk (Taner). Bu repoda `.ed5proj` yok.
- Canlı site şu an ED5 genel dünya seçicisine bakıyor ve İngilizce.

## Yapılacak
1. destanonline.com yüzeyini Türkçe Destan Online yap.
2. Studio Vocabulary + Localization → `tr`.
3. Oyun HUD / login / karakter / çanta / sohbet Türkçe.
4. İçerik adları (bölge, eşya, görev, NPC) Türkçe yazılsın.
5. Metin2 / Knight Online isim klonu yok.
